# Read Me Offline

Share an article or text, trim it, and hear it read aloud by your phone's own on-device
text-to-speech voice. No cloud voices, no account, no tracking. Android, F-Droid-clean.

It also serves a loopback speech bridge for the `local-tts-reader` Obsidian plugin.

- Spec: [`srs.md`](srs.md). Architecture: [`CONTEXT.md`](CONTEXT.md). Building:
  [`BUILDING.md`](BUILDING.md).
- Icons and store images come from `scripts/gen-brand.py` (`npm run brand`); store
  screenshots from `npm run device:screenshots`. Listing text is in
  `fastlane/metadata/android/en-US/`.
